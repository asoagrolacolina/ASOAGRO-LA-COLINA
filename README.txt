ASOAGRO LA COLINA — Eco Huevos

ARCHIVOS
- index.html: contenido y estructura de la página.
- styles.css: colores, tipografía, distribución y animaciones.
- script.js: catálogo, cantidades, pedido por WhatsApp y efecto interactivo de cáscara.

NOVEDAD: FRACTURA DORADA DE LA CÁSCARA
En la portada, haz clic o toca la ilustración de huevos. Aparecerán grietas orgánicas doradas, un halo de impacto y pequeños fragmentos. El efecto funciona con JavaScript y Canvas, sin librerías adicionales.

CÓMO ACTUALIZAR TU PÁGINA EN GITHUB
1. Descarga y extrae el ZIP.
2. Abre tu repositorio asoagro-la-colina en GitHub.
3. Entra en Code (Código) > Add file (Agregar archivo) > Upload files (Cargar archivos).
4. Sube los cuatro archivos extraídos, reemplazando los existentes cuando GitHub lo solicite. Los archivos deben quedar en la raíz del repositorio, no dentro de una carpeta.
5. Pulsa Commit changes (Confirmar cambios).
6. Espera unos minutos y recarga tu web. Si no ves los cambios, prueba Ctrl + F5.

CONFIGURACIÓN
- El número de WhatsApp está en script.js: 573214054298.
- Los precios siguen como “Precio por confirmar”; edita el arreglo PRODUCTS en script.js cuando tengas los precios reales.
- El efecto visual es interactivo, pero la ilustración actual de huevos es CSS. Puedes reemplazarla por fotografías reales más adelante.

Logo institucional: logo-asoagro.png. Mantén este archivo en la raíz del repositorio junto a index.html, styles.css y script.js.
