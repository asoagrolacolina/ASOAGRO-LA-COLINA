ASOAGRO LA COLINA — sitio web inicial
=====================================

CONTENIDO
- index.html: estructura de la página
- styles.css: diseño adaptable a celular y computador
- script.js: catálogo, selección de cantidades y pedido por WhatsApp

ANTES DE PUBLICAR
1. Abre script.js.
2. El número de WhatsApp ya está configurado: 573214054298.
3. Edita PRODUCTS con nombres, presentaciones y precios reales. Los precios están en pesos colombianos.
4. Reemplaza las ilustraciones del diseño por fotografías autorizadas de la asociación y sus productos.
5. Verifica dirección de entrega, disponibilidad, métodos de pago y políticas de tratamiento de datos antes de promocionar el sitio.

PRUEBA LOCAL
Abre index.html en un navegador. El catálogo funciona localmente. El botón de WhatsApp abrirá el pedido para el número configurado. Prueba el enlace antes de publicar.

PUBLICACIÓN SENCILLA
Una opción para una página estática es GitHub Pages. La web puede publicarse primero con una dirección gratuita de GitHub y conectarse después a un dominio propio. Consulta la documentación oficial:
https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

IMPORTANTE
Este es un prototipo inicial de catálogo y pedidos por WhatsApp; no procesa pagos, no descuenta inventario automáticamente y no guarda pedidos en una base de datos.
